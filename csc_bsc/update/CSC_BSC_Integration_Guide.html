CSC / BSC
算法与接口集成说明

本文接口均为软算法接口，用于计算硬件 R2Y 模块所需的矩阵与前后偏移寄存器值，将颜色空间转换和亮度、对比度、饱和度调整融合为一组参数。接口本身不配置硬件寄存器。

单次矩阵运算C99 / C++ 可调用S7.N + S(N+1)2026-11-09

硬件接入重点：要让这些接口计算的矩阵与 offset 生效，硬件 R2Y_MODE 寄存器必须设置为 Programmable 模式。硬件其他模式使用内置参数，不会按本接口计算的自定义系数完成处理。这个硬件模式独立于 User Config.R2Y_Mode，不可混为同一个配置。

01交付内容与调用流程

基础算法由 CSC、CSC_BSC 两组 C 接口组成，R2Y_Config 提供统一配置封装。参数在色域、范围模式或 B/C/S 调整值变化时重新计算；逐像素处理时只应用最终生成的一组矩阵与 offset。

1.1 软算法选择模式与硬件寄存器模式分开配置

配置位置作用与硬件 Programmable 的关系
R2Y_User_Config.R2Y_Mode选择软算法输入来源：L2L/L2F/F2L/F2F 自动生成基础 CSC；R2Y_Mode_PROGRAMMABLE 从 CSV 读取自定义参数。用于参数计算，不要求为了硬件使用自定义系数而设成 Programmable。
R2Y_SW_Config.RGBToYUVModeBSC_enable=0 时复制 User 的 R2Y_Mode；BSC_enable=1 时写为 R2Y_Mode_PROGRAMMABLE，供硬件选择接口生成的融合系数。这是接口输出字段。不要为了设置硬件模式而反向修改 User.R2Y_Mode。
硬件 R2Y_MODE 寄存器决定硬件使用内置参数还是软件计算并写入的矩阵、offset。只要需要应用本接口输出的参数，就必须单独写成硬件定义的 Programmable 编码。

例如 User Config 选择 R2Y_Mode_F2L，软算法自动生成 R2Y 并融合 BSC 后，驱动应将生成的矩阵和 offset 写入对应寄存器，同时将硬件 R2Y_MODE 配置成 Programmable。不要为了设置硬件模式而把 User Config 改成 R2Y_Mode_PROGRAMMABLE，否则软算法会切换为 CSV 输入路径。

软算法侧：User.R2Y_Mode = R2Y_Mode_F2L（或其他计算模式 / CSV 模式）
          Set_R2Y_BSC_Config(&User, &SW)

驱动侧：  将 SW 的矩阵、CoeffP、CoeffD 写入硬件系数寄存器
          将硬件 R2Y_MODE 写为“硬件定义的 Programmable 编码”
          按硬件规定完成更新与生效流程

以上是配置职责说明，不规定寄存器写入先后、地址或更新时序。软算法输入使用原枚举 R2Y_Mode_PROGRAMMABLE=0，驱动应依据对应模块的寄存器定义选择硬件 Programmable 编码。

R2Y_Enable=0 表示软算法输出 RGB→RGB 的 BSC 参数，并不意味着可以直接关闭硬件矩阵处理。若仍要通过硬件执行这些 BSC 参数，同样需要让硬件应用这组系数，并将硬件 R2Y_MODE 设为 Programmable。

这项要求属于调用方/驱动的硬件接入约定；接口不自动写寄存器。BSC_enable=1 时接口只把 R2Y_SW_Config.RGBToYUVMode 写为 R2Y_Mode_PROGRAMMABLE，不修改 User.R2Y_Mode，也不代替驱动完成硬件寄存器写入。

02数据与符号约定

2.1 统一采用“减去 preoffset”

列向量： output = M · (input − p) + q
逐分量： out[r] = Σc=0..2 M[r][c] · (in[c] − preoffset[c]) + postoffset[r]

其中 p=preoffset、q=postoffset。矩阵按行存储；行对应输出通道，列对应输入通道。RGB 顺序为 R/G/B，YUV 顺序为 Y/U/V。对按行存储像素的数组，等价形式为 output = (input − p) · Mᵀ + q。

preoffset 是“需要减去的值”。例如 Y2R 的 U/V preoffset 为 +0.5，应用时减去色度中心。BSC 融合后返回 new_preoffset = −Kb，所以 input − (−Kb) = input + Kb；这里的负号是亮度增加的实现方式。

2.2 浮点参数使用归一化单位

对于 N 位整数样本，统一使用 P = 2N：x = X / P。10 位取 1024，12 位取 4096。浮点矩阵、offset、Kb 不随 N 变化；将浮点 offset 转为整数码值单位时再乘 P。

03CSC 参数生成原理

3.1 从色度坐标推导基础矩阵

CSC.c 内置 R/G/B 三基色和白点的 xy 坐标，先转换为 Y=1 的 XYZ，再求三基色的缩放权重。

v(x,y) = [x/y, 1, (1−x−y)/y]ᵀ
Prgb = [vR   vG   vB]
[kR, kG, kB]ᵀ = Prgb−1 · vW

基础 R2Y 矩阵 M0 的三行为：

Y : [ kR,                     kG,                     kB                     ]
U : [ kR / (2*(kB-1)),        kG / (2*(kB-1)),        0.5                    ]
V : [ 0.5,                    kG / (2*(kR-1)),        kB / (2*(kR-1))        ]

基础 Y2R 矩阵为 M0−1。此时 U/V 是以零为中心的差分量，postoffset 或 preoffset 负责引入或移除 0.5 的数字色度中心。

系数由源码内的 xy 坐标和白点推导，未直接硬编码常见的标准系数表。尤其 CSC_BT601 使用下表中的坐标；接收团队若要与其他固定系数表逐位匹配，应以本接口的实际输出进行比对。

令 Din、Dout 为输入、输出通道的幅度对角矩阵：

M = Dout · M0 · Din−1
M[r][c] = M0[r][c] · sout[r] / sin[c]

输入范围按列缩放，输出范围按行缩放。mode 的第一个字母描述输入，第二个描述输出；例如 R2Y F2L 表示 Full RGB → Limited YUV。

本实现的 Contrast 为对亮度调整后的值直接乘增益，处理顺序为 C·(x+b)，未引入额外的中灰枢轴。B、C 以及 R2Y 与 S 之间均不做裁剪。

S 的定义与参考脚本一致：对带 offset 的整个 U/V 数值乘增益。中性输入的 U/V=0.5，在 Ks=1.25 时会变成 0.625，因此可能改变中性灰的色度。围绕固定色度中心的公式 (UV−0.5)·Ks+0.5 属于另一种处理定义，不能直接套用本文的 offset 公式。

4.2 Enable：RGB → YUV 的简单推导

原始 CSC 为 y=M·(x−p)+q，加入 B、C、S：

xbc = C·(x+b)
y = S·[M·(C·(x+b) − p) + q]
  = S·M·C·(x+b) + S·(q − M·p)

令最终表达式仍为 y=A·(x−a)+t，得到：

A = S·M·C
a = −b
t = S·(q − M·p)

实现时，Kc 乘对应的矩阵列，Ks 乘 U/V 对应的矩阵行；S 必须乘整个 q−M·p。只缩放 q、漏掉 −M·p 的缩放，会在非零 CSC preoffset 下得到错误结果。

采用 a=−b 不需要除以 Kc，因而 Kc=0 仍能正确融合。新 preoffset 与原 CSC preoffset 的数值不同，原 p 已被吸收到 t 中，最终输出与逐步计算等价。

4.3 Disable：RGB → RGB 的简单推导

Disable 的输入基矩阵必须是 I，输入 pre/post 必须全为 0。接口内部固定生成 BT709 F2F R2Y 参数，以下记为 T、p0、q0。其中 p0=0，q0=(0,0.5,0.5)ᵀ。它们用于 RGB→YUV→RGB 的内部往返，不取传入的单位矩阵作 R2Y 色域基准。

先计算经 S 调整的 YUV，再追加同一 CSC 的逆仿射变换：

y = S·[T·(C·(x+b) − p0) + q0]
r = T−1·(y−q0) + p0
  = T−1·S·T·C·(x+b)
   + T−1·[S·(q0−T·p0)−q0] + p0
A = T−1·S·T·C
a = −b
t = T−1·[S·(q0−T·p0)−q0] + p0

BT709 F2F 下可简化为：
t = T−1·(0, (Ks1−1)/2, (Ks2−1)/2)ᵀ

因此 Disable 仍然调整 B/C/S，只是最终输出保持 RGB。当 Ks1=Ks2=1 时，上式退化为 r=C·(x+b)；再令 Kb=0、Kc=1，则为单位变换，允许存在正常的浮点舍入误差。

4.4 为什么融合后只需一次矩阵运算

亮度是平移，对比度和此处的 S 是对角矩阵，CSC 是仿射变换。它们的组合仍然是仿射变换，因此可提前合成为一组 A、a、t。中间若插入裁剪、非线性曲线、色度采样等操作，则一般不能再用同一组矩阵完整等价地表示。

    uint32_t R2Y_Gamut;

所有元素必须是有限数值，不能含 NaN/Inf；超出以上区间会被参数校验拒绝。此前 10/12 位参数不越界的验证结论以这些区间及第 8 节所列 CSC 配置为前提，自定义 CSV 矩阵仍需单独检查定点范围。

输入字段用途
R2Y_Mode复用原 enum _R2Y_Mode。Programmable=0，L2L=1，L2F=2，F2L=3，F2F=4。封装内部映射至 CSC_Mode，并始终用该值计算软件矩阵。BSC_enable=1 时只把输出 RGBToYUVMode 写为 Programmable，R2Y_Mode 本身不变。
R2Y_Gamut复用原 enum R2Y_Gamut。Rec601=0，Rec709=1，Rec2020=2，P3=3，sRGB=4。sRGB 的 CSC 基色与白点采用 BT709 参数。Programmable 使用 CSV 矩阵，Disable 内部采用 BT709 F2F，SW 保留输入枚举值。
R2Y_ProgrammableR2Y_Enable=1 且模式为 Programmable 时，表示系数 CSV 路径，不能为空。其他模式不读取该路径。
R2Y_Bitwidth样本位宽 8～16。标准路径将归一化 offset 乘 2^位宽；CSV offset 已经是该位宽的整数码值，不能再次缩放。
R2Y_Enable1：RGB→YUV；0：RGB→RGB BSC，内部使用单位矩阵/零 offset 和 BT709 基准。Disable 时不打开 CSV。
BSC_enable1：使用 kb/kc/ks，仅把输出 R2Y_SW_Config.RGBToYUVMode 写为 R2Y_Mode_PROGRAMMABLE，R2Y_User_Config.R2Y_Mode 保持不变；0：BSC 关闭，kb/kc/ks 按中性值处理，RGBToYUVMode 保持 R2Y_Mode。旧 JSON 缺少该字段时默认 0。

5.5 Programmable CSV 格式与单位

Matrix,0.21264,0.7315,0.07384,-0.11459,-0.3942,0.5114,0.5,-0.4645,-0.04689
Preoffset,64,64,64
Postoffset,64,512,512

Matrix 行是 9 个按行展开的浮点系数，矩阵按 R2Y_Bitwidth 取 N 位小数，乘 2N 并舍入；Preoffset/Postoffset 行是已量化的整数码值，要求在 S(N+1) 范围 [−2N,2N−1] 内，N=R2Y_Bitwidth。中性 BSC 下直接保留 CSV 的前后 offset，例如 64、512 不会再次乘 1024 或 4096。CSV 不记录位宽，调用方应保证文件与 R2Y_Bitwidth 一致。

非中性 BSC 的自定义参数在整数样本单位下融合：A=S*M*C，a_code=−Kb*2^位宽，t_code=S*(q_code−M*p_code)。原 CSV offset 不重复定点化；融合后新产生的小数码值仅舍入为整数，并按 S(N+1) 范围检查饱和。Kb 仍采用归一化单位。中性配置直接保留原始 p/q，不做多余重分解。

支持 UTF-8 BOM、CRLF/LF、大小写不敏感的行名、带引号字段、空行、任意三行顺序及 Excel 导出的尾部空列。每行最多 4095 字节；必须且只能包含 Matrix、Preoffset、Postoffset 各一条有效记录。缺项、重复、额外非空数据、非有限数或非整数 offset 均视为格式错误。

SW 输出字段赋值规则
RGBToYUVMode / RGBToYUVGamutGamut 始终复制 User 值；BSC_enable=0 时 Mode 复制 User.R2Y_Mode，BSC_enable=1 时 Mode 写为 Programmable。User.R2Y_Mode 始终不变并用于软件矩阵计算。
RGBToYUVCoeff[9]最终 QN 矩阵，N=R2Y_Bitwidth，索引 row*3+col，S7.N 有符号值存于 int32_t。
RGBToYUVCoeffP[3]矩阵乘法前需要减去的 preoffset，S(N+1) 有符号值存于 int32_t。
RGBToYUVCoeffD[3]矩阵乘法并除以 2R2Y_Bitwidth 后相加的 postoffset，S(N+1) 有符号值存于 int32_t。

Set_R2Y_BSC_Config 返回 0 表示成功，正数为定点饱和位掩码，输出为已饱和参数，负数为失败，输出保留调用前内容。−1 为非法参数，−2 为逆矩阵错误，−3 为浮点数值范围错误，−4 为 CSV 打开/读取错误，−5 为 CSV 格式错误。Set_R2Y_Config 调用该完整入口并忽略状态返回，其输出提交规则与完整入口一致。

宿主工程已有同名结构体时，请沿用原定义并在 User Config 尾部追加字段、合并声明；不要重复 typedef。由于 User 结构新增字段，调用方应同步采用更新后的 User Config 定义。

#include <stdio.h>
#include "R2Y_Config.h"

int main(void)
{
    R2Y_User_Config user = {
        R2Y_Mode_F2L, R2Y_Gamut_Rec709, NULL, 12,
        {0.10f, -0.05f, 0.00f},  /* kb[3]: RGB, each [-0.5, 0.5] */
        {1.20f, 1.00f, 0.80f},   /* kc[3]: RGB, each [0, 2] */

    };

    int i;

    /* R2Y only: generate parameters without BSC adjustment. */
    Set_R2Y_Config(user.R2Y_Mode, user.R2Y_Gamut,
                   user.R2Y_Programmable, user.R2Y_Bitwidth, &sw);
    printf("R2Y only: M00=%ld P0=%ld D0=%ld\n",
           (long)sw.RGBToYUVCoeff[0],
           (long)sw.RGBToYUVCoeffP[0], (long)sw.RGBToYUVCoeffD[0]);

    if (Set_R2Y_BSC_Config(&user, &sw) != 0) return 1;
    printf("Generated: M00=%ld P0=%ld D0=%ld\n",
           (long)sw.RGBToYUVCoeff[0],
           (long)sw.RGBToYUVCoeffP[0], (long)sw.RGBToYUVCoeffD[0]);

    /* Programmable: CSV offsets already use 10-bit sample-code units. */
    user.R2Y_Mode = R2Y_Mode_PROGRAMMABLE;
    user.R2Y_Programmable = "r2y_programmable_example.csv";
    user.R2Y_Bitwidth = 10;

06定点格式与像素运算

6.1 格式与缩放

参数硬件格式转换有符号整数范围C 存储类型
matrixS7.N，共 N+7 位，1 符号 + 6 整数 + N 小数round(M·2N)−2N+6 ～ 2N+6−1int32_t
pre/post offsetS(N+1)，1 符号 + N 整数，共 N+1 位round(offset·2N)−2N ～ 2N−1int32_t

矩阵实数范围为 [−64,64−2−N]，offset 归一化实数范围为 [−1,1−2−N]。N 控制量化比例、小数位数、总位数和整数上下限。所有定点输出数组使用 int32_t，以容纳 N=16 时的 S7.16 矩阵和 S17 offset。

Mi = round(M · 2N)
pi = round(p · 2N)，qi = round(q · 2N)
round 的中点规则：远离零，例如 +0.5→+1，−0.5→−1

R2Y_Bitwidth 同时控制矩阵小数位数和归一化 offset 的码值单位。10 位时均乘 1024，12 位时均乘 4096。浮点矩阵随量化比例转换为对应整数系数。比如浮点系数 +0.5/−0.5，10 位量化为 +512/−512，12 位量化为 +2048/−2048。

6.2 推导整数像素应用方式

把 x=X/P 代入浮点式并将输出乘 P，有 Y=M·(X−Pp)+Pq。因此定点系数应用于整数样本时：

acc[r] = Σc Mi[r][c] · (X[c] − pi[c])
Y[r] = round(acc[r] / 2N) + qi[r]

先将样本与 offset 扩展到 int64_t 再相减、相乘和累加。负数的右移及简单的 (acc+2048)>>12 不等价于这里统一采用的中点远离零规则；第 7 节提供了同时处理正负值的整数除法实现。最终像素是否裁剪到 [0,P−1]、是否另按 Limited 范围裁剪，由调用方决定。

6.3 寄存器打包

写入这些矩阵/offset 字段时，必须同时确保硬件 R2Y_MODE 采用 Programmable 模式。否则硬件会使用其他模式的内置参数，本节打包的自定义系数无法按预期生效。该选择由驱动负责，独立于 User Config 的计算模式。

unsigned int n = user.R2Y_Bitwidth;
uint32_t matrix_mask = (1u << (n + 7)) - 1u;
uint32_t offset_mask = (1u << (n + 1)) - 1u;
uint32_t matrix_reg = (uint32_t)matrix_fixed[r][c] & matrix_mask;
uint32_t pre_reg = (uint32_t)preoffset_fixed[c] & offset_mask;
uint32_t post_reg = (uint32_t)postoffset_fixed[r] & offset_mask;

矩阵字段按 N+7 位、offset 字段按 N+1 位生成补码掩码。实际寄存器地址、字段布局及更新时序由项目驱动定义。软件像素运算使用有符号整数，从字段读回时按对应总位数符号扩展。

07完整调用示例

下面的 C 调用示例同时演示 Enable 与 Disable、定点化状态检查、负数舍入和最终像素裁剪。示例处理 12 位 RGB 样本，也可将 bits 改为 10 并输入相应码值。

C99 · 完整程序
#include <stdint.h>
#include <stdio.h>
#include "CSC_BSC.h"

/* Round x / 2^bits halfway away from zero, including negative x. */
static int64_t round_scaled(int64_t x, unsigned int bits)
{
    const int64_t scale = (int64_t)1 << bits;
    const int64_t half = scale / 2;
    int64_t whole = x / scale;
    int64_t rem = x % scale;
    if (rem >= half) {
        ++whole;
    } else if (rem <= -half) {
        --whole;
    }
    return whole;
}

static void apply_fixed(const int32_t m[3][3], const int32_t pre[3],
                        const int32_t post[3], const uint16_t input[3],
                        unsigned int bits, uint16_t output[3])
{
    int row, col;
    int64_t max_code = ((int64_t)1 << bits) - 1;
    for (row = 0; row < 3; ++row) {
        int64_t acc = 0;
        for (col = 0; col < 3; ++col) {
            int64_t delta = (int64_t)input[col] - pre[col];
            acc += (int64_t)m[row][col] * delta;
        }
        int64_t value = round_scaled(acc, bits) + post[row];
        if (value < 0) value = 0;
        if (value > max_code) value = max_code;
        output[row] = (uint16_t)value;
    }
}

static int run_demo(int enabled)
{
    const unsigned int bits = 12;
    float m[3][3] = {{1,0,0}, {0,1,0}, {0,0,1}};
    float pre[3] = {0,0,0}, post[3] = {0,0,0};
    float fused[3][3], fused_pre[3], fused_post[3];
    int32_t fixed[3][3];
    int32_t fixed_pre[3], fixed_post[3];
    uint16_t input[3] = {1024,2048,3072};
    uint16_t output[3];
    int ret;

    if (enabled) {
        ret = initparams_CSC(CSC_R2Y, CSC_BT709, CSC_F2L,
                            m, pre, post);
        if (ret != CSC_SUCCESS) {
            fprintf(stderr, "initparams_CSC failed: %d\n", ret);
            return 1;
        }
    }
    /* Disable retains identity/zero above; BT709 F2F is internal. */
    ret = CSC_BSC_Coeff(m, pre, post,
                        0.10f, -0.05f, 0.00f, /* Kb: R/G/B */
                        1.20f, 1.00f, 0.80f,  /* Kc: R/G/B */
                        1.10f, 0.90f,         /* Ks: U/V */
                        enabled, fused, fused_pre, fused_post);
    if (ret != CSC_SUCCESS) {
        fprintf(stderr, "CSC_BSC_Coeff failed: %d\n", ret);
        return 1;
    }
    ret = CSC_ParamsToFixed(fused, fused_pre, fused_post, bits,
                            fixed, fixed_pre, fixed_post);
    if (ret < 0) {
        fprintf(stderr, "CSC_ParamsToFixed invalid input: %d\n", ret);
        return 1;
    }
    if (ret != 0) {
        /* Outputs are saturated; this example rejects that configuration. */
        fprintf(stderr, "Fixed parameters saturated: mask=%d\n", ret);
        if (ret & CSC_FIXED_OVERFLOW_MATRIX)
            fprintf(stderr, "  matrix overflow\n");
        if (ret & CSC_FIXED_OVERFLOW_PREOFFSET)
            fprintf(stderr, "  preoffset overflow\n");
        if (ret & CSC_FIXED_OVERFLOW_POSTOFFSET)
            fprintf(stderr, "  postoffset overflow\n");
        return 1;
    }
    apply_fixed(fixed, fixed_pre, fixed_post, input, bits, output);
    printf("%s: RGB=(%u,%u,%u) -> %s=(%u,%u,%u)\n",
           enabled ? "Enable" : "Disable",
           (unsigned)input[0], (unsigned)input[1], (unsigned)input[2],
           enabled ? "YUV" : "RGB",
           (unsigned)output[0], (unsigned)output[1], (unsigned)output[2]);
    return 0;
}

int main(void)
{
    if (run_demo(1) != 0) return 1;
    return run_demo(0);
}

09接入要点

  1. 硬件 R2Y_MODE 必须设为 Programmable。本接口计算的是硬件自定义系数寄存器值；其他硬件模式使用内置参数。User.R2Y_Mode 只选择软算法输入来源；BSC_enable=0 时 SW.RGBToYUVMode 复制该模式，BSC_enable=1 时接口仅把 SW.RGBToYUVMode 写为 Programmable，不能反向修改 User.R2Y_Mode。
  2. 先确认输出格式。Enable 输入 R2Y 参数、输出 YUV；Disable 输入单位矩阵和零 offset、输出 RGB，BSC 仍生效。
  3. 区分归一化 offset 与 CSV 码值 offset。标准路径由 CSC_ParamsToFixed 按样本位宽转换归一化 offset；CSV 中的 offset 已是量化后的码值，不重复乘 1024/4096。
  4. 应用时减去 preoffset。融合后的负 preoffset 表示加亮度，不能再取反或改为加号。
  5. 保持运算顺序。B→C→R2Y→S；Disable 再追加 Y2R。中间插入量化或裁剪会改变结果。
  6. 按同一位宽应用矩阵系数。矩阵取 N=R2Y_Bitwidth 位小数，像素矩阵乘积除以 2N 后加上整数码值 offset。
  7. 需要检查状态时调用 Set_R2Y_BSC_Config。该完整入口和定点接口返回 0 表示成功，正数表示参数饱和，负数表示调用或读取失败。Set_R2Y_Config 设置默认 BSC 后复用完整入口，返回 void。
  8. 按有符号数运算。采用足够宽的累加器，并核对硬件的负数舍入、补码符号扩展和最终裁剪规则。
  9. 只在参数变化时重新融合。逐像素阶段无需重复计算 BT709 的逆矩阵或再次调用参数接口。
