数据来源：dpst_disable_dark_image.CSV（关闭，1256 行，约 42 分钟）/ dpst_enable_dark_image.CSV（开启，2008 行，约 67 分钟）· HWiNFO 传感器日志 · 已剔除开始段不稳定数据及异常值

一、功耗相关列的含义与相互关系

列名含义示例值与其他列的关系
CPU域CPU 封装功率 [W] CPU Package Power（RAPL PKG），CPU 芯片整体功耗 ~1.5–1.7 ≈ IA核心功率 + GT核心功率 + System Agent功率 + 剩余芯片功率
CPU域IA 核心功率 [W] CPU 计算核心（Core）部分功耗 ~0.8–0.9 CPU 封装功率的子集，占比最大
CPU域GT 核心功率 / IGPU 功率 [W] 核显（集成 GPU）功耗，二者数值相同，是同一遥测的两个别名 ~0.05 CPU 封装功率的子集；负责显示引擎/图像处理，与 DPST 算法直接相关
CPU域System Agent 功率 [W] 片上系统代理（内存控制器、总线互联等 Uncore 部分）功耗 ~0.4–0.5 CPU 封装功率的子集
CPU域剩余芯片功率 [W] 封装功率中扣除 IA/GT/SA 后的其余部分（缓存、IO 等） ~0.3 = CPU 封装功率 − IA − GT − System Agent（近似）
CPU域DRAM 总功率 [W] 内存颗粒功耗（独立 RAPL 域，不计入 CPU 封装功率） ~0.7 与 CPU 封装功率并列，两者之和更接近"处理器+内存"总耗电
CPU域系统总功率 [W]（PSys） Intel PSys 遥测域，理论上应覆盖比封装功率更广的范围 ~1.0 本数据中该值小于且不稳定于 CPU 封装功率，与理论关系倒挂，判断为该平台 PSys 采样口径异常/不完整，不能作为整机功耗使用
电池域充电速度 [W] 电池瞬时充/放电功率，负值=放电 −12.9 ~ −26.0 其绝对值 = 电池向整机（CPU+屏幕+主板+WiFi+存储+稳压损耗等所有部件）的实际供电功率，是本数据集中最接近真实整机功耗的量
电池域电池电量 [%] / 剩余容量 [Wh] / 电压 [V] 电池荷电状态、剩余能量、端电压 — 电压随电量单调下降，二者共同印证放电功率数据可信（本次两段测试电池电量均单调递减，无充电中断，测量有效）

关键结论：该日志（HWiNFO）中没有独立的屏幕/背光功率传感器，无法直接读取背光功耗。 采用「整机功耗（电池放电功率绝对值） − CPU 封装功率」估算「非 CPU 部分功耗」， 该部分主要由屏幕/背光构成（因两段测试内容均为纯暗态图像、无用户交互，WiFi/存储/风扇等其他负载可视为基本恒定）， 故其下降量可近似代表 DPST 带来的屏幕/背光功耗节省。

二、开始段不稳定数据的识别与剔除

两份日志采样间隔均为 2 秒。逐点检查「充电速度」时间序列发现：关闭日志基本从头就平稳，仅开头约 20 个点（~40 秒）功耗偏高且有小波动； 开启日志存在明显的开机/切换热身段——放电功率从起始的约 −24W 持续衰减、大幅波动（一度达 −22.9W）， 直到约第 280 个点（约 9.3 分钟后，11:17:14）才收敛并稳定在 −13~−14W 区间，此后波动幅度明显收窄。 为避免该热身段拉高「开启」侧的功耗均值、掩盖 DPST 的真实节能效果，分析中丢弃该热身段，只取之后的平稳数据。

平稳段内仍存在零星的瞬时尖峰（推测为磁盘/后台任务等与 DPST 无关的突发负载，例如开启日志第 720、1550~1580、1990 帧附近）， 进一步用 IQR 方法（1.5×四分位距）剔除这些离群点后再取均值，得到更能代表"稳态"的功耗数值。

七、方法与注意事项

  • 平稳段截取：关闭日志丢弃前 20 行（~40s），开启日志丢弃前 280 行（~9.3min，对应放电功率从 −24W 衰减收敛到 −13~14W 的热身过程），仅用截取后的数据计算均值。
  • 异常值过滤：在平稳段内对「充电速度」「CPU 封装功率」等序列做 1.5×IQR 过滤，剔除零星瞬时尖峰（推测为磁盘/后台任务等与 DPST 无关的突发负载），再计算均值，减少个别尖峰对结果的干扰。
  • 数据集缺少独立的屏幕/背光/面板功率传感器，"屏幕/背光功耗"为推算值：整机功耗（电池放电绝对值）− CPU 封装功率。剔除热身段后 CPU 侧功耗基本不变，因此该推算值的下降可直接归因于背光/显示部分，估算可信度高于处理前。
  • 两段测试时长不同（关闭约 42 分钟 / 开启约 67 分钟），电池电量在两段测试内均单调递减、无充电中断，说明放电功率读数连续可信。
  • 「系统总功率 [W]」（PSys 域）在本平台数据中出现小于 CPU 封装功率的反常现象，判断为传感器口径或采样异常，本次分析未采用该列代表整机功耗。
